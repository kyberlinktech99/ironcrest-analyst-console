// KEY CONCEPTS
SYN FLOOD (DoS)
Attacker sends massive SYN packets without completing the handshake. Server allocates resources for each half-open connection until it exhausts its table — Availability violation.
ARP POISONING (MITM)
Attacker broadcasts false ARP replies associating their MAC with the gateway IP. Victims update their ARP cache, sending traffic to the attacker instead of the real gateway.
PORT SCANNING (RECON)
Rapid SYN packets to many ports — RST responses show closed ports, SYN-ACK shows open ports. Used for reconnaissance before an attack. Not an attack itself but often a precursor.
CLEARTEXT CREDENTIAL CAPTURE
HTTP and Telnet transmit data in plaintext. A Wireshark capture on the same network can read usernames, passwords, and all content. HTTPS/SSH encrypt the payload.
