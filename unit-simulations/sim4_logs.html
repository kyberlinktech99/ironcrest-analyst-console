// KEY CONCEPTS
BRUTE FORCE vs CREDENTIAL STUFFING
Brute force tries every possible password combination. Credential stuffing uses real username/password pairs leaked from other breaches. Credential stuffing succeeds far more often because the credentials are correct — just used on the wrong site.
ACCOUNT LOCKOUT POLICY
Lock accounts after N failed attempts (typically 5–10). Prevents brute force by making it impractically slow. Downside: attackers can lock out legitimate users deliberately (DoS). Configure carefully with escalating delays rather than hard locks for critical systems.
PASSWORD SPRAYING
Instead of many passwords against one account (brute force), spray ONE common password across MANY accounts. Avoids lockout policies because each individual account sees only one failed attempt. Indicators: one failed attempt per account, many accounts, slow timing.
LOG ANALYSIS INDICATORS
Brute force: many failures on ONE account, fast timing, sequential passwords. Spraying: one failure per account, MANY accounts, slow timing. Credential stuffing: scattered failures across many accounts, then occasional sudden success. All require MFA as the primary defense.
