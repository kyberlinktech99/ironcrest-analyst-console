Access Control Matrix
An access control matrix defines who can do what to which resources. For each scenario, you'll assign the correct level of access to different roles — applying the principle of least privilege. Get it wrong and you either create a security risk or block legitimate work.
🚫DENY — no access at all
👁️READ — view only
✏️WRITE — can modify
⚙️FULL — read, write, admin
// KEY CONCEPTS
LEAST PRIVILEGE
Users and systems should have only the minimum access necessary to perform their job functions — nothing more. This limits the damage any single compromised account can cause.
ROLE-BASED ACCESS CONTROL
Access is granted based on job role, not individual identity. Everyone in the "Nurse" role gets the same access. Easier to manage than per-user permissions — and easier to audit.
SEPARATION OF DUTIES
Sensitive operations require multiple people. No single role has complete control over a critical process. Prevents both fraud and errors — a key control in financial and healthcare systems.
NEED TO KNOW
Even if someone has clearance for a classification level, they should only access information relevant to their current assignment. Clearance + need to know = authorized access.
