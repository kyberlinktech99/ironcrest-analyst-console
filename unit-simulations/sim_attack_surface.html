Attack Surface Mapper
An attack surface is every point where an attacker could try to enter or extract data from a system. Your job: study three organizations, tag each component as Vulnerable or Secured, then see how well you mapped their real risk.
// KEY CONCEPTS
ATTACK SURFACE
The total set of points where an attacker can attempt entry. Larger surfaces = more risk. Goal: reduce it.
VULNERABILITY
A weakness that could be exploited. Can be technical (unpatched software), human (weak passwords), or physical (unlocked server room).
EXPLOIT
Code or action that takes advantage of a vulnerability to cause unauthorized behavior.
SURFACE REDUCTION
Eliminating unnecessary services, closing unused ports, disabling old accounts — all shrink the attack surface.
PRINCIPLE OF LEAST PRIVILEGE
Users and systems should have only the minimum access they need — reducing the damage if any one component is compromised.
RISK = LIKELIHOOD × IMPACT
Not all vulnerabilities are equal. Prioritize based on how likely exploitation is AND how bad the result would be.
