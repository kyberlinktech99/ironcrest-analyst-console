Physical Controls Classifier
Five real-world security controls. Your job: classify each one by type AND function. Security pros need to know the difference — a camera and a lock both protect a space, but in completely different ways.
🏗️
PHYSICAL
Tangible barriers that restrict physical access — locks, fences, walls, mantraps
⚙️
TECHNICAL
Technology-based controls — keycard readers, biometric scanners, badge systems
📋
ADMINISTRATIVE
Policies, procedures, and training that govern behavior — visitor logs, clean desk policy
🔍
DETECTIVE
Controls that identify and record incidents after they occur — cameras, audit logs, motion sensors
// KEY CONCEPTS
PHYSICAL CONTROLS
Prevent unauthorized physical access — locks, fences, mantraps, security guards. First line of defense for any facility.
TECHNICAL CONTROLS
Use technology to enforce access policy — keycard readers, biometrics, badge systems. Can be logged automatically.
ADMINISTRATIVE CONTROLS
Policies and procedures that guide human behavior — visitor policies, clean desk rules, security awareness training.
DETECTIVE CONTROLS
Identify and record incidents — cameras, motion sensors, audit logs. Don't prevent attacks but enable investigation.
PREVENTIVE VS DETECTIVE
Preventive controls stop incidents from occurring. Detective controls identify incidents after the fact. Both are necessary — prevention fails, detection catches it.
LAYERED CONTROLS
Most real security controls span multiple categories. A mantrap is both physical (barrier) AND technical (badge reader). The AP exam tests control TYPE and FUNCTION separately.
