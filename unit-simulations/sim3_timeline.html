// KEY CONCEPTS
CYBER KILL CHAIN
Lockheed Martin's 7-stage attack model: Reconnaissance → Weaponization → Delivery → Exploitation → Installation → Command & Control → Actions on Objectives. Every attack follows a version of this sequence.
RECONNAISSANCE INDICATORS
Port scans, DNS lookups, OSINT activity, HTTP requests to admin pages. Often the first evidence of an attack. Detecting recon early gives defenders the most time to respond.
LATERAL MOVEMENT
After initial compromise, attackers move through the network to reach higher-value targets. Indicators: unusual internal connections, privilege escalation events, access to new systems from a recently compromised host.
LOG CORRELATION
Connecting events across multiple log sources (firewall, auth logs, IDS, endpoint) to reconstruct the full attack sequence. No single log tells the whole story — correlation is the analyst's primary skill.
