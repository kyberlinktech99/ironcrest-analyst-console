// KEY CONCEPTS
IMPLICIT DENY
Best practice firewall rule: the last rule DENY ALL. If no earlier rule matches the traffic, it's blocked by default. Never rely on "allow all" as your baseline.
STATEFUL VS STATELESS
Stateless firewalls check each packet in isolation. Stateful firewalls track connection state — they know if a packet is part of an established session. Most modern firewalls are stateful.
PRINCIPLE OF LEAST ACCESS
Only permit what is explicitly needed. Block everything else. This limits the blast radius if a device is compromised — it can only communicate on allowed ports and protocols.
DANGEROUS PORTS
Port 23 (Telnet) transmits in plaintext — always block. Port 3389 (RDP) on public IPs is a brute force magnet. Port 445 (SMB) should never be internet-facing. Know your risky ports.
