Patch Priority Ranker
Security teams can't patch everything at once. You'll review CVEs with CVSS scores and context clues, then rank them from highest to lowest priority. CVSS score alone doesn't determine priority — exploitability, asset criticality, and exposure all matter.

// KEY CONCEPTS
CVSS — WHAT IT MEASURES
Common Vulnerability Scoring System scores vulnerabilities from 0–10 on: Attack Vector (network vs. local), Attack Complexity, Privileges Required, User Interaction, and Impact on C/I/A. Higher = more severe, but not always highest priority.
EXPLOITABILITY CONTEXT
A CVSS 9.8 with no known exploit in the wild is lower priority than a CVSS 7.5 with an active exploit kit available. Confirmed exploitation elevates any CVE's real-world priority significantly.
ASSET CRITICALITY
A CVSS 6.0 on a patient monitoring system or payment server may warrant faster response than a CVSS 9.0 on an isolated test machine with no internet access. The asset's role determines exposure and impact.
ZERO-DAY vs PATCHED
A zero-day has no vendor patch available — mitigations (WAF rules, network isolation, disabling the service) must be applied immediately. A known CVE with an available patch should be patched on the standard SLA timeline based on severity.
