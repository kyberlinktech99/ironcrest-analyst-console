// KEY CONCEPTS
DEFENSE-IN-DEPTH
Using multiple layers of security so that no single failure leads to total compromise. Also called "layered defense."
PHYSICAL CONTROLS
Locks, keycards, cameras, security guards. Prevent physical access to systems. The first layer an attacker must bypass.
TECHNICAL CONTROLS
Firewalls, encryption, MFA, antivirus. Software and hardware that enforce security policy automatically.
ADMINISTRATIVE CONTROLS
Policies, training, access reviews, incident response plans. Shape human behavior to reduce risk.
KILL CHAIN
The sequence of steps an attacker must complete to succeed. Disrupting any one step can prevent the breach.
COST vs. RISK
Not every control is worth its cost. Strong defense-in-depth maximizes risk reduction within budget constraints.
