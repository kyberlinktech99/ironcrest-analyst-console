# Ironcrest Analyst Console

Interactive SOC investigation environment for the Ironcrest Cyber Partners cybersecurity classroom.

## V2.1 Development
The `v2.1-development` branch contains the classroom web build.

### Student workflow
Assigned Case → Log Explorer → Evidence Locker → Timeline / Case Notes → Analyst Assessment → SOC Briefing

### Case U1-001
**Find the Intruder — Possible Account Compromise**

All names, addresses, organizations, and telemetry in the case are synthetic classroom data. The student application intentionally does not contain a teacher answer key.

## Local test
Open `index.html` in a browser.

## Publishing
After classroom testing, merge V2.1 to `main` and publish the repository with GitHub Pages.
